This is my personal flatpak repository. Here you can find and install flatpak packages of my applications.

Setup

Instructions
  1. Install flatpak on your machine by following the instructions for your distribution.
  2. Add this flatpak repository.
    Download and install the flatpak repository file or run: 
    flatpak remote-add --user --if-not-exists ckardaris.com https://ckardaris.com/flatpak/ckardaris.com.flatpakrepo
  3. Install applications.
    Download and install an application flatpakref file or run: 
    flatpak install --user ckardaris.com <app-id>
